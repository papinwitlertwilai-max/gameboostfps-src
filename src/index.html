Auto Ping Tune

วัด ping จริงไปยัง DNS หลายเจ้า แล้วเลือก + ตั้งตัวที่ตอบเร็วที่สุดให้อัตโนมัติ พร้อมตรวจหาอะแดปเตอร์ที่ใช้งานอยู่ด้วย index — รองรับทั้ง LAN/WiFi และ Windows ทุกภาษา

ⓘ ping ขึ้นกับ เน็ต / ระยะทางไป server / ISP ไม่ใช่สเปคคอม — เครื่องแรงแค่ไหน ถ้าเน็ตเส้นเดียวกัน ping ก็เท่าเดิม สิ่งที่ปรับได้จริงคือเลือก DNS ที่เร็วสุดกับที่ของคุณ
กด Run เพื่อเริ่มวัด ping

โปรแกรมที่เปิดตอนบูต

ปิดตัวที่ไม่จำเป็นเพื่อให้บูตไวขึ้นและคืน RAM/CPU ตั้งแต่เปิดเครื่อง — ปิดแล้วยังเปิดโปรแกรมเองได้ตามปกติ ไม่ได้ถอนการติดตั้ง

ⓘ รายการที่ปิดจะถูกย้ายไปเก็บไว้ ไม่ได้ลบทิ้ง กดเปิดกลับได้ทุกเมื่อ · บางรายการต้องใช้สิทธิ์ Administrator (HKLM)
🛡️

Create restore point

สร้างจุดกู้คืน Windows ก่อนปรับแต่ง เผื่ออยากย้อนทุกอย่างกลับในคลิกเดียวผ่าน System Restore

↩

Revert applied tweaks

คืนค่า tweak ที่ apply ไปแล้วทั้งหมดกลับเป็นค่าเดิมของ Windows (best-effort) — ไม่แตะ restore point

⟳

Reset power plans

รีเซ็ต Power Plan ทั้งหมดกลับเป็นค่าโรงงานของ Windows ด้วย powercfg -restoredefaultschemes

💾

Registry backups

ก่อน Optimize เป็นชุด แอปสำรองค่า registry เดิมเป็นไฟล์ .reg (เก็บ 5 ชุดล่าสุด) — ถ้ามีปัญหา ดับเบิลคลิกไฟล์ .reg เพื่อคืนค่าเดิม แล้ว restart
